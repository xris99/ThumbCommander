# ThumbCommander
This is the ganme ThumbCommander for the Thumby and ThumbyColor platform.
It brings along a common graphic and audio framework, based on the grayscale implementation from the Thumby and IMA Audio Lib for the Thumby.
While this is by far not as powerful as the ThumbyColor Engine, the framework enables single source games working on Thumby and ThumbyColor with minimal code differences required.

All is adopted for the ThumbyColor. Audio uses correct threading and background music and FX playback.
Cutscene videos are saved in 8bit delta rendering format to reduce filessize and use a compression matching the ThumbyColor ressources

All keys can be changed in Setting Menu. Audio Volume can be set. Vibration can be turned on / off
In default mode cutscenes can be canceled with the MENU key (B key on Thumby).

As there is no emulator for the ThumbyColor available, the game brings along it's own emulator (tested on Mac, sorry no PC available - but should run as well).

All content, game elements are taken from our friends at wcnews.com.

Feel free to reuse libaries and PC emulator to develop games for the ThumbyColor and Thumby platform.
